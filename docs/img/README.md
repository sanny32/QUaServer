# Client illustrations

The JPG screenshots and GIF animations in this directory show the installed Windows version of [OpenUaExplorer](https://github.com/sanny32/OpenUaExplorer) with the QUaServer guide examples.

The captures use English UI labels and a light theme. Illustrations show only the panels, dialogs or settings relevant to each example. Panels of different sizes are separate images in the documentation, without added backgrounds or scaled text. Data Access captures use active subscriptions and show the relevant columns in full. The example servers listen on `127.0.0.1:4841` to avoid an existing server on port 4840. The methods captures use the snippets in the Methods chapter, including `increaseNumber`. The Users and Encryption captures use a test certificate and private key configured as described in the Encryption chapter.

The history animations show repeated reads of data and event history. Each alarm illustration shows the address tree, the changing input value, and the latest event as the alarm is enabled and activated. All frames come from the running client and local example servers.
